# A&R 模拟题库

纯静态、离线可用的刷题应用，部署于 GitHub Pages。

## 功能

- 📝 **443 道题内置**（单选 236 / 多选 207），打开即刷
- 🎯 **顺序练习**（答完确认即看对错与解析）与**模拟考试**（交卷统一判分）
- 📚 题数可选 5 / 10 / 20 / 50 / 100 / **全部（443）**，支持按分类筛选
- ❌ **错题本**：答错自动收录，答对 2 次自动消灭，支持错题专练
- 📊 **学习统计**：总正确率、分类正确率、成绩走势
- 📥 **题库可更新**：在「题库管理」里直接上传 Excel（.xlsx/.xls/.csv），自动识别题干/选项/答案/解析列
- 📱 手机友好，可「添加到主屏幕」当 App 用
- 💾 学习记录保存在浏览器本地（localStorage），无需登录、不上传服务器

## 访问

GitHub Pages 部署后访问：`https://<用户名>.github.io/<仓库名>/`

## 本地开发

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
```

推送到 main 分支会自动通过 GitHub Actions 重新部署 `dist/`。

## 题库 Excel 格式

支持以下列名（自动识别，不区分顺序）：

| 字段 | 支持的列名 |
|------|-----------|
| 题干 | 题干 / 题目 / 问题 |
| 选项 | 选项A、选项B… 或 A、B、C、D 单列 |
| 答案 | 答案 / 正确答案 / 参考答案 |
| 解析 | 解析 / 答案解析 |
| 分类 | 分类 / 章节 / 科目 |
| 题型 | 题型 / 类型（也可按答案自动判断） |
| 难度 | 难度 / 难度等级 |

> 本应用为学习用途的内部复习工具，题目内容来自个人题库。
